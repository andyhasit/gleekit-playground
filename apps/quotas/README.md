# Quotas

Daily checklist, weekly targets.

### User stories

##### Task list

1. Thinks of task.
2. Enters it, optionally adding to list.

##### Day planning

1. Select tasks.
2. Set values where applicable.



Some tasks are one-off, others to be repeated every day.
